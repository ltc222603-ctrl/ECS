## 项目简介

本项目是一个面向电商场景的智能客服系统，主要用于处理用户在购物过程中的订单查询、收货地址修改、订单取消、售后申请、物流投诉、商品咨询以及商品图片识别等需求。

系统以 Rasa Pro / CALM 作为对话管理与任务编排核心，通过 Rasa Action Server 调用后端业务接口、机器学习模型接口以及 GraphRAG 检索接口，实现多轮对话中的意图识别、槽位收集、任务路由和结果返回。后端业务数据通过 FastAPI、MySQL 与 SQLAlchemy ORM 进行统一管理，知识查询部分基于 GraphRAG 与 Neo4j 构建商品知识图谱检索能力。

## 核心功能

### 1. 订单与售后业务处理

系统支持电商客服中常见的订单类业务，包括：

- 订单查询
- 商品明细查询
- 收货信息查询
- 修改收货地址
- 取消订单
- 申请售后
- 售后原因选择与处理

该部分主要依赖 MySQL 业务数据库，通过 FastAPI 接口完成数据查询、修改与状态更新。

### 2. 物流投诉处理

用户可以针对订单物流状态发起投诉。系统会根据用户选择的订单和物流信息，结合投诉等级模型判断投诉严重程度，并返回对应的处理结果。

投诉等级模型将投诉划分为：

- low
- medium
- high

该模型用于辅助客服系统进行投诉优先级判断，提高投诉处理效率。

### 3. 商品咨询问答

系统支持用户对商品、品牌、类别、属性等内容进行自然语言咨询。  
当用户提出商品相关问题时，系统会进入 GraphRAG 查询流程，通过实体抽取、入口节点检索、Cypher 语句生成、验证修正和 Neo4j 检索，最终生成结构化的商品咨询结果。

### 4. 多模态商品识别

本项目新增了基于商品图片的多模态识别功能。用户可以上传商品图片，系统会将图片转换为 Base64 格式后传递给多模态模型进行分析。

多模态模型会生成两类 JSON 结果：

#### 搜索用实体 JSON

用于 GraphRAG 检索，主要包含：

- 品牌
- 商品类别
- 商品名
- 型号
- 颜色
- 关键属性

#### 图片描述 JSON

用于解释模型判断依据，主要包含：

- 外观特征
- 材质或风格描述
- 颜色特征
- 细节描述
- 判断依据
- 置信度信息

随后，系统会将搜索用实体 JSON 转换为检索文本，并传入已有 GraphRAG 模块。GraphRAG 根据抽取到的实体进行知识图谱检索，并将检索结果与图片描述 JSON 中的判断依据进行融合，最终向用户返回商品识别结果。

## 系统架构

系统整体架构分为三层：

1. 主请求链路  
   用户接入层、Rasa Pro / CALM、Rasa Action Server、FastAPI 业务接口层。

2. 电商客服业务能力层  
   包括交易履约与售后业务、物流投诉处理、产品咨询问答、多模态商品识别。

3. 数据、模型与知识支持层  
   包括 MySQL 业务数据库、SQLAlchemy ORM、投诉等级模型、多模态模型服务、GraphRAG 与 Neo4j 知识图谱。
